# MedScan AI

MedScan AI is a React-based diagnostic platform prototype for exploring AI-assisted medical imaging workflows. The app presents a modern clinical dashboard with dedicated workspaces for chest X-ray, brain MRI, and dermatology cases, along with analytics for recent diagnostic activity.

## Features

- Multi-module diagnostic interface for:
  - Chest X-ray analysis
  - Brain MRI analysis
  - Dermatology image review
- Simulated diagnosis output with:
  - Confidence scores
  - Class probability breakdowns
  - Explainability insights
  - Clinical-style metrics
- Analytics overview for cross-module performance and recent cases
- Supabase integration for storing and retrieving analysis records

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Supabase JS client and Edge Functions
- Lucide icons


## Notes

The diagnosis engine in this prototype uses deterministic simulated outputs for demonstration purposes. Supabase is used to persist analysis records and power the analytics experience.
